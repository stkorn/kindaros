# Domain docs

## Layout

This repo uses single-context domain documentation:
- CONTEXT.md at the repository root
- docs/adr/ for architecture decisions

## Consumer rules

Before domain exploration, read CONTEXT.md and relevant ADRs.
If those files do not exist, continue without requiring their creation.
The domain-modeling skill creates them when terms or decisions are resolved.

Use the vocabulary defined in CONTEXT.md.
If a proposal conflicts with an ADR, identify that ADR and explain the conflict.
